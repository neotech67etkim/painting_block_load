# 해양사업본부 블록도장공장 시뮬레이션

해양사업본부 블록도장공장(도장1공장/도장2공장)의 블라스팅셀·도장셀 배치를 웹에서 실척(scale)으로
보여주고, 그 안에 선박 블록들을 배치·이동시키며 공정 흐름(블라스팅 → 도장)과 일정, 만적 여부를
시뮬레이션하는 프론트엔드 전용(vanilla JS, 빌드 도구 없음) 웹앱입니다.

## 실행 방법

빌드 과정 없이 정적 파일만으로 동작합니다. ES 모듈을 사용하므로 `file://`로 직접 열지 말고
로컬 서버로 띄워서 접속하세요.

```bash
python3 -m http.server 8000
# 또는
npx serve .
```

이후 브라우저에서 `http://localhost:8000` 접속.

## 데이터 출처 및 가정

- 셀 규격/적치가능 블록수는 제공된 "블라스팅셀/도장셀 Size(건축규격)" 표를 기준으로 입력했습니다
  (`js/data.js`).
- 도장2공장의 셀 번호는 항공사진 라벨(블라스팅셀 #2, 도장셀 #3~#6)과 표(블라스팅셀 #1~#2,
  도장셀 #1~#8)가 서로 달라, **표 기준**(블라스팅 #1~#2, 도장 #1~#8)으로 통일했습니다.
- 야드 내 배치 좌표(공장/셀의 x,y 위치)는 항공사진의 상대적 배치를 참고한 **개략도(schematic)**
  이며, 실측 측량 좌표가 아닙니다. 자재창고/관제실/도료창/장비보관쉘터/구 선행도장공장(조선2야드)은
  표에 상세 규격이 없어 참고용 랜드마크로만 표시했습니다.
- 블록 데이터(`js/store.js`의 시드 데이터)는 항공사진에 보이는 블록 라벨(1A/1B, 2A/2B, …)을
  본떠 만든 샘플이며, 실제 생산 일정이 아닙니다. `localStorage`에 저장되며 "블록관리" 탭에서
  직접 추가/수정/삭제하거나 JSON으로 내보내기/가져오기 할 수 있습니다.

## 기능

- **배치도**: 공장/셀을 실척 SVG로 표시. 기준일자를 바꾸면 그 날짜에 각 셀을 점유 중인 블록이
  슬롯 격자에 표시됩니다. 셀을 클릭하면 우측에 상세 정보(규격, 면적, 점유율, 점유 블록 목록)가
  나타납니다. 적치가능 수를 초과하면 셀이 붉은색으로 표시되고, 초과 배치된 블록도 슬롯을 늘려
  모두 표시합니다.
- **일정표**: 셀별 날짜 타임라인(간트 형태)으로 블록이 블라스팅셀 → 도장셀로 이동하는 흐름과
  기간별 만적/초과 여부를 한눈에 볼 수 있습니다.
- **블록관리**: 블록 목록 조회 및 추가/수정/삭제. 블록별로 여러 공정 구간(블라스팅/도장 각각
  셀·시작일·종료일)을 입력해 전체 흐름을 정의합니다. JSON 내보내기/가져오기로 데이터를
  백업하거나 다른 환경과 공유할 수 있습니다.

## 파일 구조

```
index.html          앱 셸 (탭, 대시보드, 날짜 선택)
css/style.css        스타일
js/data.js           야드/공장/셀 정적 데이터 (표 기반)
js/store.js          블록 데이터 저장소 (CRUD, localStorage, 조회 헬퍼)
js/layout.js         배치도 탭 (SVG 렌더링, 셀 상세 패널)
js/schedule.js        일정표 탭 (간트 렌더링)
js/blocks.js          블록관리 탭 (목록/폼)
js/main.js            탭 전환, 날짜 컨트롤, 전체 조립
```
