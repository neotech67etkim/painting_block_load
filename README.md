# 해양사업본부 블록도장공장 시뮬레이션

해양사업본부 블록도장공장(도장1공장/도장2공장)의 블라스팅셀·도장셀 배치를 웹에서 실척(scale)으로
보여주고, 그 안에 선박 블록들을 배치·이동시키며 공정 흐름(블라스팅 → 도장)과 일정, 만적 여부를
시뮬레이션하는 프론트엔드 전용(vanilla JS, 빌드 도구 없음) 웹앱입니다.

## 실행 방법

빌드 과정 없이 정적 파일만으로 동작합니다. ES 모듈을 사용하므로 `file://`로 직접 열지 말고
로컬 서버로 띄워서 접속하세요.

```bash
python3 -m http.server 8000
# 또는
npx serve .
```

이후 브라우저에서 `http://localhost:8000` 접속.

## 데이터 출처 및 가정

- 셀 규격/적치가능 블록수는 제공된 "블라스팅셀/도장셀 Size(건축규격)" 표를 기준으로 입력했습니다
  (`js/data.js`).
- 도장2공장은 엑셀 배치도 표기 기준(2026-08-29 확인)으로, BLASTING SHOP과 PAINT'G SHOP이 각각
  독립적으로 1부터 번호가 매겨집니다(블라스팅 2-1·2-2, 도장 2-1~2-8). 건물 내 실제 위치 순서
  (정문 쪽부터)는 블라스팅 2-1(#1)·2-2(#2) → 도장 2-1(#3)~2-8(#10)로 이어지며, 이 물리적
  일련번호는 각 셀 배치도 라벨에 `(#N)`으로 함께 표시됩니다. 블라스팅 2-1(#1) 셀은 다른 셀과
  달리 건물 내에서 90도(반시계 방향) 회전된 형태로 지어져 있어 가로/세로가 다른 블라스팅셀과
  반대입니다.
- 야드 내 배치 좌표(공장/셀의 x,y 위치)는 항공사진·배치도의 상대적 배치를 참고한
  **개략도(schematic)**이며, 실측 측량 좌표가 아닙니다. 도장1공장/도장2공장 외 다른 건물
  (자재창고/관제실/도료창/장비보관쉘터/구 선행도장공장 등)은 사용자 요청(2026-08-29)에 따라
  배치도에서 제외했습니다. 도장1공장과 도장2공장은 좌측 끝단(x=0)을 맞춰 정렬되어 있습니다.
- 공장 밖 "야적/출고 대기" 구역(#1 앞·#2 앞·공장 앞 옥외장·YARD 출고 BLOCK·도장공장 앞
  적치장)은 실제 건물이 아니라 블록이 잠시 쌓이는 공간이라 정식 규격이 없으며, 일일작업현황
  가져오기에서 이 구역의 블록도 함께 보여주기 위한 가상 셀로 배치도 하단에 표시됩니다.
- 블록 데이터(`js/store.js`의 시드 데이터)는 항공사진에 보이는 블록 라벨(1A/1B, 2A/2B, …)을
  본떠 만든 샘플이며, 실제 생산 일정이 아닙니다. `localStorage`에 저장되며 "블록관리" 탭에서
  직접 추가/수정/삭제하거나 JSON으로 내보내기/가져오기 할 수 있습니다.

## 실적 엑셀(.xlsx) 가져오기

"블록관리" 탭에서 아래 서식의 엑셀 파일을 업로드하면 자동으로 블록/일정을 생성합니다.
파싱은 전부 브라우저 안(클라이언트 사이드)에서 이루어지며 파일이 서버로 전송되지 않으므로,
사내망 드라이브(V: 등)에 있는 보안 파일도 로컬 브라우저의 파일 선택창으로 직접 열기만 하면
됩니다 — 파일 내용은 이 저장소나 외부로 전달되지 않습니다.

**기대 서식 (2행 헤더, 데이터는 3행부터, A~K열)**

| A | B | C~F (SIZE) | G~H (계획) | I~J (실적) | K |
|---|---|---|---|---|---|
| 호선 | 블록 | 소지면적(㎡), L, B, H | 착수, 완료 | 착수, 완료 | 비고 |

**자동 배치 규칙**

- 도장 시작일(실적 착수, 없으면 계획 착수)을 기준으로 그 직전 2일을 블라스팅 기간으로 생성합니다
  (1일차 = 블록 입고, 2일차 = 블라스팅 작업). 도장 종료일은 실적 완료, 없으면 계획 완료를 사용합니다.
- 원본 데이터에는 어느 물리적 셀을 썼는지 기록이 없으므로, 블록 크기(L×B)가 실제로 들어가는
  셀들 중 해당 기간에 정원 초과가 없는 셀을 우선 배정하고, 여러 셀이 가능하면 더 작은 셀부터
  채워 큰 홀(도장1공장 #3)로만 몰리지 않도록 분산시킵니다. 모든 셀이 초과되면 초과가 가장 적은
  셀에 배정하고, 배치도/일정표에서 빨간색으로 표시됩니다. → **셀 배정은 실제 이력이 아니라
  용량 기준 추정치이며, 정원 대비 부하(며칠에 몇 개가 몰리는지)를 보기 위한 시뮬레이션입니다.**
- 크기(L·B) 정보가 없는 행은 10m×10m로 가정합니다. 착수일 정보가 전혀 없는 행은 제외되며
  가져오기 결과 요약에 제외 건수가 표시됩니다.
- "기존 블록 교체" / "기존 블록에 추가" 중 선택할 수 있습니다.

## 일일작업현황(.xlsx) 여러 개 가져오기

"도장작업계획 (YY. M월 D일) 요일" 형식으로 매일 업데이트되는 현황 파일들을 날짜순으로 모아
셀 점유 이력을 재구성합니다(`js/importDailyStatus.js`). 실적 엑셀과 마찬가지로 전부 브라우저
안에서 파싱됩니다.

**서식**: 도장1공장/도장2공장 각각 `BLOCK` 헤더 아래로 셀그룹 라벨(예: `(B/S) 1-1`, `1-3A(금양)`,
`(PAINT) #2-1(금양)`)이 병합되어 있고, 그 아래에 그 날 그 셀에 있는 블록들이
`호선(블록번호) 회사 | m² | 착수 | 작업 | 검사 | 완료일` 행으로 나열되는 것을 전제로 합니다.
`#1 앞`/`#2 앞`/`공장 앞 옥외장`/`YARD 출고 BLOCK`/`도장공장 앞 적치장` 라벨은 공장 밖 야적
가상 셀(`yard-*`)로 매핑됩니다.

**단순화한 부분**(2026-08-29 확인):
- "작업" 열의 세부 단계(B/S&1ST/2ND/3RD/4TH준비/FINAL 등)는 구분하지 않고, 그 셀에 있으면
  "점유 중"으로만 취급합니다. 같은 블록이 같은 셀에 연속으로 나타나는 날짜 구간을 하나의
  공정(route leg)으로 묶습니다.
- 블록 크기(W×L)는 이 파일에 면적(㎡)만 있고 L×B가 없어 **정사각형으로 근사**합니다
  (`meta.approxSquare: true`). 정확한 L×B가 있는 실적 엑셀을 같은 블록에 나중에 가져오면
  그쪽 값으로 덮어써야 더 정확합니다.

이 파서는 사용자가 촬영한 화면 사진만으로 만든 1차 버전이라(실제 .xlsx 파일로 검증 전),
가져오기 결과 요약에 파일별 인식 건수와 "못 알아본 셀 라벨"을 표시합니다. 실제 파일로
가져와 봤을 때 라벨이 못 알아본 것으로 나오면 `js/importDailyStatus.js`의 `LABEL_RULES`를
그 라벨에 맞게 고치면 됩니다.

## 기능

- **배치도**: 공장/셀을 실척 SVG로 표시. 기준일자를 바꾸면 그 날짜에 각 셀을 점유 중인 블록이
  실제 치수(w×l) 비율 그대로 셸프 패킹되어 표시되어, 셀 안에 실제로 들어맞는지 눈으로 확인할
  수 있습니다. 셀을 클릭하면 우측에 상세 정보(규격, 면적, 점유율, 점유 블록 목록)가 나타납니다.
  적치가능 수를 초과하거나 사용 가능 영역을 벗어나는 블록은 셀 경계에서 잘리고 빨간 점선으로
  표시됩니다.
- **일정표**: 셀별 날짜 타임라인(간트 형태)으로 블록이 블라스팅셀 → 도장셀로 이동하는 흐름과
  기간별 만적/초과 여부를 한눈에 볼 수 있습니다.
- **블록관리**: 블록 목록 조회 및 추가/수정/삭제. 블록별로 여러 공정 구간(블라스팅/도장 각각
  셀·시작일·종료일)을 입력해 전체 흐름을 정의합니다. JSON 내보내기/가져오기로 데이터를
  백업하거나 다른 환경과 공유할 수 있습니다.

## 파일 구조

```
index.html          앱 셸 (탭, 대시보드, 날짜 선택)
css/style.css        스타일
js/data.js           야드/공장/셀 정적 데이터 (표 기반)
js/store.js          블록 데이터 저장소 (CRUD, localStorage, 조회 헬퍼)
js/layout.js         배치도 탭 (SVG 렌더링, 셀 상세 패널)
js/schedule.js        일정표 탭 (간트 렌더링)
js/blocks.js          블록관리 탭 (목록/폼)
js/importXlsx.js       실적 엑셀(.xlsx) 파싱 + 셀 자동 배정
js/importDailyStatus.js 일일작업현황(.xlsx) 여러 개 파싱 + 이력 재구성
js/vendor/xlsx.full.min.js  SheetJS(xlsx) 라이브러리 (오프라인 사용을 위해 로컬에 포함)
js/main.js            탭 전환, 날짜 컨트롤, 전체 조립
```
